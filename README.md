## What it does

`main.ts` (plain TypeScript, no dependencies, no network) writes a single sentence — a post road joining every library, printing press, and market stall on Earth, carrying a letter to China before your tea cools — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (defaults to `/output`).

## Run

```sh
node main.ts
```
